# Vikas Rawat — Portfolio

Static multi-page portfolio (HTML, CSS, vanilla JS). No build step, deploys on Vercel as-is.

## Pages
- `index.html` — Home
- `experience.html` — Work history
- `projects.html` — Case studies and GitHub repos
- `skills.html` — Skills by area
- `contact.html` — Email, LinkedIn, GitHub, CV

## To finish
1. **CV:** upload your PDF as `assets/Vikas_Rawat_CV.pdf`.
2. **LinkedIn:** replace `https://www.linkedin.com/in/your-linkedin-id` in all five HTML files.
3. **Photo:** upload `assets/img/vikas.jpg` and replace the placeholder block in `index.html`.
4. **Experience:** add dates and job titles in `experience.html`.

Light/dark mode follows the device setting and remembers the visitor's choice.
